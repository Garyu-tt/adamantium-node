# Adamantium-node R07-QA — безопасность SVG и синхронизации

**Статус:** независимая QA-поправка поверх draft PR #41. Не предназначена для самостоятельного production-деплоя.

## Исправленные дефекты

### 1. Скрытые порты `+N` больше не скрывают неправильные связи

В предыдущем рендерере ребро со скрытым входным или выходным портом исключалось из рисования **до** проверки направления, типа и семантики. Теперь `layoutCapsuleCanvas` всегда проверяет каждое ребро и запрет семантик разрешений, в том числе полностью скрытые каналы. Только затем применяется фильтр визуального отображения. Идентификаторы портов не объединяются и связи не создают привилегий.

### 2. Операции редактора откатываются при отказе localStorage

`CapsuleNativeCanvas.mutateWithPersistence()` фиксирует исходные Graph/Template/Positions/Selection перед изменением. Создание контейнера, извлечение подграфа и создание типизированного соединения становятся атомарными относительно удачного сохранения в localStorage. При переполнении, блокировке записи или другой ошибке модель и позиции откатываются, а UI сообщает об отказе. Перетаскивание карточки тоже возвращается к начальным координатам, если запись после отпускания указателя не удалась.

Ошибка второстепенного `onUpdate` больше не превращает успешно записанное состояние в ложную ошибку сохранения.

### 3. Защита от перезаписи свежего состояния Sidebar

Контроллер запоминает байтовое содержимое последнего успешно прочитанного/записанного снимка. Перед сохранением он повторно читает текущее значение ключа `adamantium.capsule-studio.r01`. Если другое окно или iframe уже изменило состояние, запись **отклоняется**, вместо бесшумной потери данных. После явного `refresh()` можно редактировать актуальную версию.

Это **не атомарный cross-tab CAS**: браузерное localStorage не предоставляет операции «сравнить-и-заменить». Одновременные записи между проверкой и сохранением всё ещё возможны. Для действительно конкурентного multi-agent editing потребуется серверный авторизованный Graph Manager с ревизиями и транзакциями; R05/R06 обеспечивают лишь неисполняемый контур приёмки предложений.

## Верификация

- В независимой временной рабочей копии owner Linux Node.js v22.16.0: **86/86 тестов**, ноль пропусков/ошибок.
- Node.js v24.11.1: **86/86 тестов**, ноль пропусков/ошибок.
- В обоих запусках был обязательным реальный предварительно собранный canonical Universal Graph C++17 G0 из ToolBox PR #143; `ADAMANTIUM_G0_REQUIRED=true`.
- Добавлены adversarial-тесты скрытых портов, quota failure, отката схемы/соединений/перетаскивания, ошибки уведомления после записи и предотвращения stale last-writer-wins.
- Изменения зеркально синхронизированы в source и `node-red-contrib-adamantium-capsules/resources`; существующий byte-exact plugin test остаётся зелёным.

## Границы

SVG-панель остаётся независимым **editor-only** слоем над основным Node-RED workspace, а не сериализованными Node-RED runtime nodes или native Universal Graph IR persistent CAS. Работающие приложения, потоки Node-RED, политика MAS, VM121/VM122 и JediControl не менялись. Окончательная интерактивная проверка в браузере остаётся отдельным пунктом; Windows JediControl desktop-01 офлайн в последней живой проверке.

Не сливать автоматически без независимого QA и прохождения Windows/Linux CI.
